Testing as Specification: A Pedagogical Paradigm for Requirement Engineering in AI-Assisted Programming

Abstract

Recent work in Artificial Intelligence in Education (AIED) focuses on prompt-engineering pedagogy, which often lacks academic merit. Beyond prompt engineering, researchers have not widely investigated how AI-assisted programming is changing student learning objectives. Including well-specified requirements in prompts to AI-coding assistants improves code quality. Crucially, prior work demonstrates that software testing forces students to identify and specify requirements: a skill we argue translates to prompting skills for AI-assisted programming. However, AIED literature has not recognized the pedagogical connection between requirement engineering and software testing. The comprehensive capabilities of AI coding assistants enable previously non-technical students to pursue computer science through "vibe coding," necessitating new teaching methodologies for requirement engineering. Previous work fails at incorporating Large Language Models (LLMs) into a testing pedagogy that scaffolds requirement engineering. Thus, we propose using software testing as a pedagogical vehicle to teach requirements engineering. We propose using Large Language Models (LLMs) to simulate help-seeking behaviors, enabling students to learn software testing by teaching the LLM. The LLM iteratively probes requirements by asking the real student to develop and define test-case inputs and outputs from ill-defined system descriptions. The primary contributions of this paper include: a theoretically grounded paradigm that improves requirement engineering pedagogy by teaching software testing; and practical suggestions for creating and testing AI-supported pedagogical systems for requirement engineering grounded in software testing theory.
