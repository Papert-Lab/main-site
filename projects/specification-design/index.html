Specification Design and Exceptional AI-Assisted Programmers

Abstract

AI coding agents bridge the gap between natural-language problem solving and machine-readable code. Because computer behavior can now be fully specified in natural language and translated into code through AI coding agents, we argue that specification skills, which have traditionally been learned through code implementation, must now be taught explicitly to enable students and professionals to write programs without mastering abstract programming languages.

Prior work, however, conflates requirement engineering with prompt engineering, scenario-based testing, and probing software specifications, making it difficult to define precise learning practices for specification pedagogy. Requirement engineering and software testing have traditionally been framed as refinement and confirmatory activities, respectively, yet both resemble (though do not equal) the mechanisms for eliciting specifications from ill-specified requirements.

This paper reviews these misconceptions, establishes canonical definitions and learning practices for AI-assisted programming, defines a new specification-based paradigm, and outlines future research and pedagogical agendas.
