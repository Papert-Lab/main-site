Patrons

Generates personalized letter URLs (patrons on /phil, angels on /investing). Each add is a commit to phil/patrons.json on Papert-Lab/main-site; Vercel redeploys automatically (~1 min).

How to create the token (one time)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Resource owner: Papert-Lab · Repository access: Only main-site
  3. Permissions → Repository permissions → Contents: Read and write (nothing else)
  4. Paste it here. It never leaves this browser (kept in localStorage when “remember” is checked).
